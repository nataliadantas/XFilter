# X 内容屏蔽器 — 安装说明

## 安装步骤

1. 打开 **Edge 浏览器**，在地址栏输入：

   ```text
   edge://extensions/
   ```

   然后按回车。

2. 打开左上角的 **【开发人员模式】** 开关。

3. 点击 **【加载解压缩的扩展】** 按钮。

4. 选择本文件夹：

   ```text
   XFilter
   ```

5. 安装完成后，打开 [x.com](https://x.com/) 并刷新页面即可生效。

---

## 使用方法

* 点击浏览器右上角的插件图标，可以直接快速添加一个屏蔽词。
* 或右键插件图标 → **扩展选项**，打开完整规则页面。

---

## 规则说明

每行填写一个词，包含该词的帖子或回复会被自动隐藏。

默认同时匹配：

* 正文
* 用户名

### 仅匹配用户名

使用 `u:` 开头，例如：

```text
u:小明
```

### 仅匹配正文

使用 `t:` 开头，例如：

```text
t:广告
```

### 使用正则表达式

使用 `r:` 开头，匹配 **正文 + 用户名**，例如：

```text
r:\b(sell|buy)\b
```

### 注释

开头的行是注释，不会生效。

---

## 其他说明

* 页面右下角会显示 **“已屏蔽 N 条”**。
* 点击该提示，可以临时恢复全部被隐藏的帖子。
* 修改规则后会 **立即生效**，无需刷新页面。
